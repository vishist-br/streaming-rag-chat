# Sample documents licence

The files in this folder were written for this project. Tidewater Robotics,
the Heron-2 drone and the Fleet API are fictional, and any resemblance to real
products is coincidental.

They are released under [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/):
you can copy, modify and distribute them without asking permission.

Fictional documents are used on purpose. A language model cannot answer
questions about them from its training data, so a correct answer in the
evals has to come from retrieval.
